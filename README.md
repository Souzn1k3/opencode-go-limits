# OpenCode Go Limits

Виджет для рабочего стола Windows, который показывает лимиты OpenCode Go — 5 часов, неделю и месяц — без открытия браузера.

![Виджет OpenCode Go Limits](widget.png)

## Возможности

- Три полосы прогресса: 5-часовой, недельный и месячный лимиты с обратным отсчётом до сброса
- Окно без рамки, всегда поверх других окон; перетаскивается мышью, позиция запоминается
- Обновление каждые 5 минут (F5 — вручную)
- Цветовая индикация: зелёный ниже 60%, жёлтый 60–85%, красный от 85%
- Необязательное уведомление Windows, когда 5-часовой лимит превышает порог (по умолчанию 85%)
- Необязательный автозапуск вместе с Windows
- Без зависимостей: один exe, работает на Windows 10/11 со встроенным PowerShell 5.1

## Требования

- Windows 10 или 11
- Подписка [OpenCode Go](https://opencode.ai/go)
- Установленный и авторизованный `opencode` (`opencode auth login`), чтобы в `%USERPROFILE%\.local\share\opencode\auth.json` лежал ключ `opencode-go`

## Скачивание и запуск

1. Скачайте `OpenCode Limits.exe` из [последнего релиза](releases/latest)
2. Запустите. Если SmartScreen покажет предупреждение, выберите «Подробнее» → «Выполнить в любом случае» (exe не подписан)
3. Виджет появится в правом нижнем углу экрана

Закрывается кнопкой ✕, клавишей Esc или Alt+F4 — приложение завершается полностью. Чтобы открыть снова, запустите exe. Если оно уже запущено, повторный запуск просто поднимет окно наверх.

## Как это работает

`OpenCode Limits.exe` — небольшой лаунчер со встроенным скриптом PowerShell. При запуске он распаковывает скрипт в `%LOCALAPPDATA%\OpenCodeLimits\app` и запускает его скрыто. Скрипт читает API-ключ из `auth.json` и каждые 5 минут обращается к `https://opencode.ai/zen/go/v1/usage`. Ключ отправляется только на `opencode.ai`; приложение хранит лишь свои настройки в `%APPDATA%\opencode-limits-widget`.

## Настройки

Правый клик по виджету → **Настройки...**: интервал обновления, уведомления, порог срабатывания, автозапуск, «окно поверх всех». Те же пункты есть в контекстном меню виджета.

## Сборка из исходников

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

Требуются Windows PowerShell 5.1 и компилятор .NET Framework (`csc.exe`, входит в состав Windows). На выходе — один файл `OpenCode Limits.exe`.

| Файл | Назначение |
| --- | --- |
| `launcher.cs` | C#-лаунчер: распаковывает встроенный скрипт и запускает его скрыто |
| `limits-widget.ps1` | Сам виджет (интерфейс WinForms, запросы к API, настройки) |
| `widget.ico` | Иконка приложения |
| `build.ps1` | Сборка однофайлового exe через `csc.exe` |
